# 물리학

> 세계는 놀랄 만큼 적은 수의 법칙으로 놀랄 만큼 많이 설명된다.

7과목 32강. 갈릴레오의 낙하 실험에서 양자역학의 해석 논쟁까지, 물리학이 세계를 설명해 온 순서를 그대로 따라간다.

## 커리큘럼

| 과목 | 강 수 | 다루는 것 |
|---|---|---|
| ① 역학 | 5강 | 갈릴레오와 뉴턴, 운동 법칙, 만유인력, 에너지·운동량 보존, 회전과 진동 |
| ② 열과 에너지 | 4강 | 온도와 열, 열역학 법칙, 엔트로피, 통계역학의 시각 |
| ③ 전자기학 | 5강 | 전하와 전기장, 전류와 회로, 자기, 맥스웰 방정식, 전자기파 |
| ④ 파동과 빛 | 4강 | 파동의 언어, 소리, 빛과 광학, 간섭과 회절 |
| ⑤ 상대성이론 | 4강 | 특수상대성, 시공간, 일반상대성, 블랙홀과 중력파 |
| ⑥ 양자역학 | 6강 | 양자의 탄생, 파동함수, 불확정성, 해석 논쟁, 원자와 스펙트럼, 양자 기술 |
| ⑦ 입자와 우주 | 4강 | 표준모형, 네 가지 힘, 대칭과 보존, 미해결 문제들 |

상태: 편찬 예정. 수학 서가 완간 후 착수한다.
