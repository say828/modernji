# 경제학

> 경제학은 돈의 학문이 아니라, 희소한 것을 두고 사람들이 어떻게 선택하는가의 학문이다.

6과목 26강. 경제적 사고방식에서 출발해 미시·거시·금융·국제경제를 거쳐, 경제사상사와 행동경제학으로 닫는다.

## 커리큘럼

| 과목 | 강 수 | 다루는 것 |
|---|---|---|
| ① 경제적 사고방식 | 4강 | 희소성과 선택, 기회비용, 인센티브, 시장과 가격의 정보 기능 |
| ② 미시경제학 | 5강 | 수요와 공급, 탄력성, 기업과 비용, 경쟁과 독점, 시장실패와 외부효과 |
| ③ 거시경제학 | 5강 | GDP, 인플레이션, 실업, 경기변동, 재정정책과 통화정책 |
| ④ 화폐와 금융 | 4강 | 화폐의 본질, 은행과 신용창조, 금융시장, 금융위기의 해부 |
| ⑤ 국제경제 | 4강 | 비교우위와 무역, 환율, 무역정책 논쟁, 세계화와 불평등 |
| ⑥ 경제사와 경제사상 | 4강 | 스미스와 고전파, 마르크스, 케인스와 하이에크, 행동경제학 |

상태: 편찬 예정.
