# 생물학

> 생물학의 어떤 것도 진화의 빛 없이는 의미를 갖지 않는다 (도브잔스키).

7과목 30강. 생명의 정의에서 세포·유전·진화를 거쳐 뇌와 면역까지, 생명 현상의 논리를 층위별로 올라간다.

## 커리큘럼

| 과목 | 강 수 | 다루는 것 |
|---|---|---|
| ① 생명이란 무엇인가 | 4강 | 생명의 정의, 생명의 화학적 기초, 생명의 기원, 생물 분류의 체계 |
| ② 세포 | 4강 | 세포설, 세포 구조, 물질대사와 효소, 세포분열 |
| ③ 유전학 | 5강 | 멘델, DNA 이중나선, 유전자 발현, 돌연변이, 유전공학과 CRISPR |
| ④ 진화 | 5강 | 다윈, 자연선택, 종분화, 인류의 진화, 진화에 대한 오해들 |
| ⑤ 생태학 | 4강 | 개체군, 군집과 먹이그물, 생태계와 물질순환, 생물다양성 위기 |
| ⑥ 신경과학 | 4강 | 뉴런과 신호, 뇌의 구조, 감각과 운동, 학습과 기억의 생물학 |
| ⑦ 미생물과 면역 | 4강 | 세균과 바이러스, 마이크로바이옴, 선천면역과 적응면역, 항생제와 내성 |

상태: 편찬 예정.
