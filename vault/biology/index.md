# 생물학

> 생물학의 어떤 것도 진화의 빛 없이는 의미를 갖지 않습니다 (도브잔스키).

## 이 서가를 읽는 법

1. **순서는 ①→⑦이 기본입니다.** 세포와 유전이 바닥이고, 진화가 전체를 꿰는 실이 됩니다.
2. 화학 서가(생체분자)와 의학과 인체 서가(질병·면역)로 자연스럽게 이어집니다.
3. 모든 강은 사전시험 1문제로 열고 인출 문제 4문제로 닫습니다. 틀린 문제가 곧 오늘의 수확입니다.
