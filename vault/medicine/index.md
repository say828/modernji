# 의학과 인체

> 몸은 평생 쓰는 유일한 기계인데, 대부분은 설명서를 읽지 않는다.

5과목 22강. 인체 시스템의 설계도에서 시작해 질병의 원리, 진단과 치료의 논리를 지나 건강 정보를 스스로 판별하는 리터러시까지 다룬다.

## 커리큘럼

| 과목 | 강 수 | 다루는 것 |
|---|---|---|
| ① 인체의 설계 | 5강 | 세포에서 기관까지, 순환계, 호흡계, 소화계, 근골격계 |
| ② 조절과 방어 | 4강 | 신경계, 내분비계, 면역계, 항상성 |
| ③ 질병의 원리 | 4강 | 질병이란 무엇인가, 감염병, 암, 만성질환 |
| ④ 의학의 도구 | 4강 | 진단의 논리, 약리학 기초, 백신, 임상시험과 근거중심의학 |
| ⑤ 의학사와 건강 리터러시 | 5강 | 의학의 역사, 공중보건, 영양 과학 읽는 법, 수면과 운동, 건강 정보 판별법 |

상태: 편찬 예정. 이 서가는 교양 지식이며 개별 의학적 판단은 의료인의 진료를 따른다.
