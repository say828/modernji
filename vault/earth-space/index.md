# 지구와 우주

> 우리는 움직이는 판 위에서, 평범한 별 곁을 도는 행성에 산다. 둘 다 안 지 100년이 안 됐다.

5과목 22강. 발밑의 지구 내부에서 시작해 대기와 기후, 지구의 역사를 지나 태양계와 우주론까지 시선을 넓힌다.

## 커리큘럼

| 과목 | 강 수 | 다루는 것 |
|---|---|---|
| ① 행성 지구 | 4강 | 지구 내부 구조, 판구조론, 지진과 화산, 암석과 광물 |
| ② 대기와 해양 | 4강 | 대기의 구조, 날씨의 원리, 해류, 기후와 기후변화 |
| ③ 지구의 역사 | 4강 | 지질시대와 연대 측정, 화석, 대멸종, 인류세 논쟁 |
| ④ 태양계 | 5강 | 태양, 지구형 행성, 목성형 행성, 달, 소행성·혜성과 행성 탐사 |
| ⑤ 별과 우주 | 5강 | 별의 일생, 은하, 빅뱅 우주론, 암흑물질과 암흑에너지, 외계행성과 생명 |

상태: 편찬 예정.
