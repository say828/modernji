# 수학의 언어 4강. 수 체계: 자연수에서 복소수까지

> 새로운 수는 발견되기 전에 먼저 필요해졌다. 풀리지 않는 방정식이 수의 우주를 넓혀 왔다.

## 풀고 시작

```quiz
Q: 유리수 체계에 머무를 수 없게 만든, 즉 실수로의 확장을 강제한 방정식은?
- x + 3 = 1
- 2x = 1
-* x² = 2
- x² = -1
E: x + 3 = 1은 음수(정수)를, 2x = 1은 분수(유리수)를 요구한다. x² = 2의 해 √2는 유리수가 아님이 증명되므로 유리수 바깥의 수, 곧 실수가 필요하다. x² = -1은 실수로도 풀리지 않아 복소수를 부른다.
```

## 확장의 논리: 닫혀 있지 않은 곳에서 수가 태어난다

자연수 ℕ은 덧셈과 곱셈에 닫혀 있지만 뺄셈에는 닫혀 있지 않다. 3 - 5의 답이 없기 때문이다. 수 체계의 역사는 이런 결핍을 메우는 확장의 연쇄로 정리된다.

| 체계 | 풀리지 않는 방정식 | 확장으로 얻는 수 |
| --- | --- | --- |
| ℕ | x + 3 = 1 | 음수와 0을 더해 ℤ |
| ℤ | 2x = 1 | 분수를 더해 ℚ |
| ℚ | x² = 2 | 무리수를 더해 ℝ |
| ℝ | x² = -1 | 허수를 더해 ℂ |

각 확장은 이전 체계를 부분으로 품고 연산 법칙을 보존한다. 3강의 동치관계가 여기서 일한다. 유리수는 분수 표기들의 동치류로 지어지며, 1/2과 2/4가 같은 수인 이유는 같은 동치류에 속하기 때문이다.

## 히파소스의 발견: 비(比)가 아닌 크기

피타고라스 학파의 신조는 "만물은 수와 수의 비"였다. 그런데 한 변이 1인 정사각형의 대각선 √2는 어떤 정수의 비로도 표현되지 않는다. 2강에서 전개한 귀류법 증명이 바로 그 사실의 증명이다. 전승에 따르면 이 발견은 학파의 일원 히파소스(Hippasus, 기원전 5세기경)와 연관되며, 그가 비밀을 누설한 죄로 바다에 던져졌다는 이야기가 전해진다. 이 극적인 일화 자체는 후대의 전설로 사료적 근거가 약하다. 그러나 **통약 불가능한 크기의 발견이 그리스 수학의 세계관을 뒤흔든 사건**이었다는 것은 분명하다. 그리스인들은 이후 수 대신 기하학적 크기를 중심으로 이론을 재정비했다.

## 실수의 완비성: 틈이 없는 직선

유리수는 조밀하다. 어떤 두 유리수 사이에도 유리수가 무한히 있다. 그런데도 √2가 있어야 할 자리에는 구멍이 있다. 유리수만으로 수직선을 만들면 곳곳이 뚫린 직선이 된다. 실수 ℝ을 실수답게 만드는 결정적 성질이 **완비성**(completeness)이다. 직관적으로 말해 수직선에 틈이 전혀 없다는 성질이며, "위로 유계인 집합은 반드시 최소상계를 갖는다"는 형태로 정식화된다. 1872년 데데킨트(Dedekind)는 유리수 전체를 두 무리로 자르는 절단(cut)으로 실수를 구성해 이 성질을 보장했다. 극한, 연속, 미분과 적분, 곧 해석학 전체가 이 성질 하나 위에 서 있다.

## 허수의 수용사: 조롱에서 평면으로

x² = -1은 오랫동안 "해 없음"으로 처리됐다. 전환점은 2차가 아니라 3차방정식이었다. 카르다노(Cardano)가 1545년 『아르스 마그나』에서 3차방정식의 해법을 공개한 뒤, 봄벨리(Bombelli)는 실수 해가 분명히 존재하는 방정식인데도 그 해법의 계산 중간에 음수의 제곱근을 통과해야만 답이 나오는 경우가 있음을 보였다. 쓸모가 존재의 승인을 앞선 것이다. 데카르트는 이런 수를 "상상의 수"(imaginary number)라 불렀는데, 이는 조롱에 가까운 명명이었다. 이후 오일러가 기호 i를 도입하고, 가우스가 복소수를 평면 위의 점으로 시각화하면서 의심은 사실상 끝났다. 복소수 ℂ 안에서는 상수가 아닌 모든 다항방정식이 해를 갖는다(대수학의 기본정리). 방정식이 강제해 온 확장의 사슬이 여기서 완결된다. 그러나 확장이 끝났다고 수의 이야기가 끝난 것은 아니다. 5강에서 수 개념은 무한의 크기라는 전혀 다른 방향으로 확장된다.

## 인출 문제

```quiz
Q: 수 체계 확장에서 각 단계를 강제한 결핍의 짝으로 옳은 것은?
-* ℕ은 x + 3 = 1에, ℤ는 2x = 1에, ℚ는 x² = 2에, ℝ은 x² = -1에 막혔다
- ℕ은 2x = 1에, ℤ는 x + 3 = 1에, ℚ는 x² = -1에, ℝ은 x² = 2에 막혔다
- 모든 확장은 x² 형태의 방정식 때문에 일어났다
- 확장은 방정식과 무관하게 측정의 편의 때문에 일어났다
E: 뺄셈의 결핍이 정수를, 나눗셈의 결핍이 유리수를, √2의 무리수성이 실수를, 음수의 제곱근이 복소수를 낳았다. 각 확장은 이전 체계에서 풀리지 않는 특정 방정식에 대응한다는 것이 확장 논리의 핵심이다.

Q: 히파소스 일화에서 역사적으로 신뢰할 수 있는 핵심은?
- 히파소스가 익사형에 처해졌다는 처형 기록
-* 정수의 비로 표현되지 않는 크기의 발견이 피타고라스 학파의 세계관과 충돌했다는 사실
- 그리스 시대에 √2의 소수 전개가 계산되었다는 사실
- 피타고라스 본인이 무리수 증명을 남겼다는 사실
E: 익사 이야기는 후대의 전설로 사료적 근거가 약하다. 확실한 것은 통약 불가능한 크기의 발견 자체와 그것이 "만물은 수의 비"라는 신조에 가한 충격이다. 전설과 사실을 구분하는 것이 지적으로 정직한 독법이다.

Q: 유리수 수직선의 문제, 곧 실수의 완비성이 해결한 결핍은?
- 유리수의 개수가 유한하다는 것
- 두 유리수 사이에 다른 유리수가 없다는 것
-* 조밀한데도 √2 같은 자리에 구멍이 있다는 것
- 유리수에 음수가 포함되지 않는다는 것
E: 유리수는 조밀하지만(어떤 두 유리수 사이에도 유리수가 무한히 있다) 완비적이지 않다. 조밀함과 틈이 없음은 다른 성질이며, 그 구멍을 모두 메운 것이 실수다. 유리수는 무한하고 음수도 포함하므로 나머지 보기는 성립하지 않는다.

Q: 수학자들이 허수를 진지하게 받아들이게 된 결정적 계기는?
- 가우스가 2차방정식을 풀기 위해 허수를 발명해서
-* 3차방정식의 실수 해를 구하는 계산 과정에 음수의 제곱근이 필요했기 때문에
- 물리학 실험에서 허수가 직접 관측되어서
- 데카르트가 허수의 존재를 강력히 옹호해서
E: 봄벨리가 보인 것처럼, 답이 분명히 실수인 3차방정식조차 해법의 중간 단계에서 음수의 제곱근을 지나가야 했다. 피할 수 없는 쓸모가 승인을 앞당긴 것이다. 데카르트는 오히려 "상상의 수"라는 경멸 섞인 이름을 붙인 쪽이었다.
```

## 생각해볼 질문 (정답 없음)

- 복소수 다음의 확장인 사원수(quaternion)에서는 곱셈의 교환법칙이 깨진다. 확장이 언제나 공짜가 아니라면, 우리는 새 수를 얻기 위해 어떤 법칙까지 포기할 수 있는가.
