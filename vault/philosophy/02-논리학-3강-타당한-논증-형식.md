# 논리학 3강. 타당한 논증 형식

> 타당성은 형식의 성질입니다. 좋은 형식 네 개와 가짜 형식 두 개만 구분해도 일상 추론의 오류 대부분이 걸러집니다.

## 풀고 시작

```quiz
Q: "비가 오면 땅이 젖는다. 땅이 젖어 있다. 따라서 비가 왔다." 이 추론은 어떨까요?
- 타당하다
-* 부당하다, 후건을 긍정했다
- 전제가 거짓이라 불건전할 뿐 타당하다
- 귀납이라서 판정 불가다
E: 후건긍정의 오류입니다. 땅은 살수차 때문에 젖었을 수도 있죠. P→Q에서 Q로부터 P를 끌어낼 수 없습니다. 그럴듯해 보인다는 것이 이 오류의 무서운 점입니다.
```

## 타당한 형식 네 개

논증의 타당성은 내용이 아니라 형식이 결정합니다(철학입문 3강). 그렇다면 좋은 형식을 몇 개나 외워야 할까요? 다행히 일상과 철학에서 가장 많이 쓰는 타당한 형식은 네 개뿐입니다.

**1. 전건긍정 (modus ponens)**

```
P → Q,  P  ⊢  Q
비가 오면 땅이 젖는다. 비가 온다. 따라서 땅이 젖는다.
```

**2. 후건부정 (modus tollens)**

```
P → Q,  ¬Q  ⊢  ¬P
비가 오면 땅이 젖는다. 땅이 안 젖었다. 따라서 비가 안 왔다.
```

과학의 반증이 바로 이 형식입니다. "이론이 옳다면 이 예측이 맞아야 한다. 예측이 틀렸다. 따라서 이론이 틀렸다." 포퍼의 반증주의(과학철학 과목)가 후건부정 하나로 서 있죠.

**3. 선언 삼단논법**

```
P ∨ Q,  ¬P  ⊢  Q
범인은 안이거나 밖에 있다. 안에 없다. 따라서 밖에 있다.
```

**4. 가언 삼단논법**

```
P → Q,  Q → R  ⊢  P → R
조건문의 사슬 연결. 미끄러운 비탈 논증이 악용하는 형식이기도 하다 (4강).
```

## 부당한 가짜 형식 두 개

진짜보다 위험한 것이 짝퉁입니다. 타당한 형식과 겉모습이 비슷해서 더 위험하죠.

**후건긍정의 오류**는 P → Q, Q ⊢ P 형태의 부당한 추론입니다. "천재는 괴짜다. 그는 괴짜다. 따라서 천재다." 조건문의 화살표를 거꾸로 탄 것이죠.

**전건부정의 오류**는 P → Q, ¬P ⊢ ¬Q 형태의 부당한 추론입니다. "열심히 하면 성공한다. 그는 열심히 안 했다. 따라서 실패한다." 성공의 다른 길(운, 재능)이 있을 수 있죠.

두 오류의 공통 뿌리는 하나입니다. **P → Q를 Q → P나 ¬P → ¬Q와 혼동**하는 것이죠. P → Q와 진리값이 항상 같은 것은 대우(¬Q → ¬P)뿐입니다.

## 귀류법: 철학의 필살기

상대의 주장을 이기는 가장 우아한 방법은 무엇일까요? 상대의 말을 일단 다 받아 주는 것입니다. **귀류법(reductio ad absurdum)**은 상대의 주장 P를 참이라고 가정하고, 거기서 모순을 도출해 ¬P를 증명합니다. "√2가 유리수라고 하자 → 모순 → 따라서 무리수다"가 그 예죠. 철학사의 명장면 상당수가 귀류법입니다. 소크라테스의 대화법도 상대의 정의를 받아들인 뒤 모순을 끌어내는 귀류법 구조죠.

## 인출 문제

```quiz
Q: 과학의 반증 논리 "이론 T가 옳다면 예측 E가 관찰된다. E가 관찰되지 않았다. 따라서 T는 틀렸다"의 형식은 무엇일까요?
- 전건긍정
-* 후건부정
- 선언 삼단논법
- 후건긍정의 오류
E: P→Q, ¬Q ⊢ ¬P인 후건부정(modus tollens)입니다. 타당한 형식이므로 반증은 논리적으로 확실하죠. 반면 예측이 맞았다고 이론이 참이라고 하면 후건긍정의 오류가 됩니다.

Q: "성공한 사람은 일찍 일어난다. 나는 일찍 일어난다. 따라서 나는 성공한다"의 문제는 무엇일까요?
-* 후건긍정의 오류다
- 전건부정의 오류다
- 타당하지만 전제가 거짓이다
- 선언지가 빠졌다
E: P(성공)→Q(일찍 기상)에서 Q를 긍정해 P를 끌어냈습니다. 화살표를 거꾸로 탄 후건긍정의 오류죠. 자기계발서 논증의 상당수가 이 형식입니다.

Q: P → Q와 진리값이 항상 같은 문장은 무엇일까요?
- Q → P
- ¬P → ¬Q
-* ¬Q → ¬P
- P ∧ Q
E: 대우(¬Q→¬P)만 원 조건문과 동치입니다. Q→P(역)와 ¬P→¬Q(이)는 참·거짓이 갈릴 수 있고, 이 둘을 원문과 혼동하는 것이 후건긍정·전건부정 오류의 뿌리죠.

Q: 귀류법의 구조로 옳은 것은 무엇일까요?
- P를 가정하고 P가 유용함을 보여 P를 증명한다
-* P를 가정하고 모순을 도출해 ¬P를 증명한다
- ¬P를 가정하고 ¬P가 불쾌함을 보여 P를 증명한다
- P와 ¬P를 모두 가정해 둘 다 버린다
E: 귀류법은 상대 주장을 참으로 가정한 뒤 모순을 끌어내 그 부정을 증명합니다. 유용함·불쾌함은 참·거짓과 무관하죠. √2 무리수 증명과 소크라테스 대화법이 대표 사례입니다.
```
