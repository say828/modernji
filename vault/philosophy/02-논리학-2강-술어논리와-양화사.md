# 논리학 2강. 술어논리와 양화사

> 명제논리는 "소크라테스는 죽는다"의 속을 못 본다. 술어논리가 문장을 열어 주어와 술어를 꺼낸다.

## 풀고 시작

```quiz
Q: "모든 사람에게는 사랑하는 사람이 있다"와 "모두가 사랑하는 한 사람이 있다"는 같은 뜻인가?
- 같다, 표현만 다르다
-* 다르다, 양화사의 순서가 다르다
- 앞 문장이 뒤 문장을 함축한다
- 두 문장 모두 명제가 아니다
E: 다르다. 앞은 ∀x∃y(각자 자기의 y가 있으면 됨), 뒤는 ∃y∀x(한 명의 y를 전원이 사랑함)다. 양화사 순서가 뜻을 바꾼다. 이 구분이 술어논리의 핵심 기술이다.
```

## 명제논리의 한계

1강의 도구로 저 유명한 논증을 분석해 보자. "모든 인간은 죽는다(P). 소크라테스는 인간이다(Q). 따라서 소크라테스는 죽는다(R)." 명제논리로는 P, Q, R 세 개의 무관한 문자일 뿐이라 결론이 도출되지 않는다. 문장 **안의 구조**(누가, 어떤 성질을)를 볼 도구가 필요하다. 프레게가 1879년 『개념표기법』에서 이 도구를 만들었고, 이것이 현대 논리학의 출생신고다.

## 술어와 양화사

- **술어(predicate)**: 성질이나 관계. "x는 인간이다"를 H(x), "x는 죽는다"를 M(x)로 쓴다.
- **보편 양화사 ∀**: "모든 x에 대하여". ∀x(H(x) → M(x)) = 인간인 모든 것은 죽는다.
- **존재 양화사 ∃**: "어떤 x가 존재하여". ∃x(H(x) ∧ ¬M(x)) = 죽지 않는 인간이 있다.

소크라테스 논증은 이제 도출된다. ∀x(H(x)→M(x))와 H(s)에서 M(s)가 기계적으로 나온다.

주의: "모든"은 →와 짝이 되고("인간이라면 죽는다"), "어떤"은 ∧와 짝이 된다("인간이면서 안 죽는 것이 있다"). 이 짝을 바꿔 쓰는 것이 초심자의 대표 실수다.

## 양화사의 순서가 세계를 바꾼다

- ∀x∃y L(x,y): 모든 x에게 각자 사랑하는 y가 있다. (각자 다른 상대여도 됨)
- ∃y∀x L(x,y): 어떤 한 y가 있어 모든 x가 그를 사랑한다. (전 인류의 단일 연인)

수학의 "모든 수보다 큰 수는 없다 / 어떤 수보다 큰 수는 항상 있다", 일상의 "모든 문제에는 원인이 있다 / 모든 문제의 단일 원인이 있다"(음모론의 문법)가 전부 이 구분이다. 철학 논증의 오류 상당수가 양화사 순서 바꿔치기에서 나온다.

## 부정과 양화사

¬∀x P(x) = ∃x ¬P(x). "모두가 착한 것은 아니다"는 "안 착한 누군가가 있다"와 같다. ¬∃x P(x) = ∀x ¬P(x). "귀신은 없다"는 "모든 것은 귀신이 아니다"와 같다. 부정이 양화사를 통과하면 ∀와 ∃가 뒤집힌다.

## 인출 문제

```quiz
Q: "죽지 않는 인간이 있다"의 올바른 기호화는?
- ∀x(H(x) → ¬M(x))
-* ∃x(H(x) ∧ ¬M(x))
- ∃x(H(x) → ¬M(x))
- ¬∀x(H(x) ∧ M(x))
E: 존재 양화사는 ∧와 짝이다. "인간이면서 죽지 않는 것이 존재한다". ∃x(H(x)→¬M(x))는 인간이 아닌 것 하나만 있어도 참이 되는 이상한 문장이 된다.

Q: 명제논리가 소크라테스 논증을 처리하지 못한 이유는?
- 전제가 세 개라서
-* 문장 내부의 주어·술어 구조를 볼 수 없어서
- 진리표가 너무 커져서
- 조건문의 규약 때문에
E: 명제논리는 문장을 통째로 P, Q로 취급한다. "모든 인간"과 "소크라테스"의 연결은 문장 안의 구조라서, 술어와 양화사를 도입한 술어논리(프레게)가 필요했다.

Q: ¬∀x(정치인(x) → 거짓말쟁이(x))와 같은 뜻은?
-* 거짓말쟁이가 아닌 정치인이 적어도 한 명 있다
- 모든 정치인은 거짓말쟁이가 아니다
- 거짓말쟁이인 정치인이 적어도 한 명 있다
- 정치인은 존재하지 않는다
E: 부정이 ∀를 통과하면 ∃¬가 된다. "모든 정치인이 거짓말쟁이인 것은 아니다" = "거짓말 안 하는 정치인이 있다". 전체 부정("모두 아니다")과 부분 부정("모두인 것은 아니다")의 구분이다.

Q: "모든 사건에는 원인이 있다"에서 "세계 전체의 단일한 첫 원인이 있다"로 넘어가는 논증의 문제는?
- 전제가 거짓이다
- 결론이 명제가 아니다
-* ∀x∃y를 ∃y∀x로 바꿔치기했다
- 술어가 정의되지 않았다
E: 각 사건마다 각자의 원인(∀x∃y)에서 모든 사건의 공통 원인 하나(∃y∀x)는 도출되지 않는다. 우주론적 신 존재 증명에 대한 고전적 반박 중 하나가 바로 이 양화사 순서 지적이다.
```
