# 지리학

> 지도는 세계를 보여주는 동시에 왜곡한다. 지리학은 공간이 인간사를 어떻게 규정하는지 묻는다.

4과목 16강. 지도와 투영법의 거짓말에서 시작해 자연지리·인문지리를 지나 자원과 국경의 지정학까지 다룬다.

## 커리큘럼

| 과목 | 강 수 | 다루는 것 |
|---|---|---|
| ① 지도와 공간 | 4강 | 지도의 역사, 투영법의 왜곡, GIS와 공간 데이터, 지명과 공간 인식 |
| ② 자연지리 | 4강 | 지형의 형성, 기후대, 물과 하천, 생물지리 |
| ③ 인문지리 | 4강 | 인구, 도시화, 산업 입지, 문화 경관 |
| ④ 지정학 | 4강 | 지정학 고전 이론, 자원과 에너지, 국경과 분쟁, 기후변화의 지정학 |
