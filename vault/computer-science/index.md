# 컴퓨터과학

> 컴퓨터과학은 컴퓨터에 대한 학문이 아니라 계산에 대한 학문이다. 망원경이 천문학이 아니듯이.

6과목 26강. 이진법과 논리회로라는 바닥에서 시작해 알고리즘·네트워크·데이터를 지나 인공지능의 원리와 한계까지 올라간다.

## 커리큘럼

| 과목 | 강 수 | 다루는 것 |
|---|---|---|
| ① 컴퓨터의 원리 | 4강 | 이진법과 정보, 논리회로, 폰 노이만 구조, 운영체제 |
| ② 알고리즘과 자료구조 | 5강 | 알고리즘이란, 정렬과 탐색, 자료구조, 복잡도와 P-NP, 계산 불가능성 |
| ③ 프로그래밍의 세계 | 4강 | 언어의 역사, 패러다임, 추상화와 모듈화, 소프트웨어 공학 |
| ④ 네트워크와 인터넷 | 4강 | 인터넷의 구조, 웹, 암호와 보안, 분산 시스템 |
| ⑤ 데이터의 시대 | 4강 | 데이터베이스, 빅데이터, 머신러닝 기초, 데이터 윤리 |
| ⑥ 인공지능 | 5강 | AI의 역사, 신경망과 딥러닝, 거대언어모델, AI와 사회, AI의 한계와 미래 |

상태: 편찬 예정.
