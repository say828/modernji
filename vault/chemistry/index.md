# 화학

> 세계의 모든 물질은 100여 종의 원소가 만드는 조합의 결과다.

5과목 20강. 원자론의 역사에서 시작해 결합·반응의 원리를 거쳐, 재료·에너지·약이라는 물질 문명까지 간다.

## 커리큘럼

| 과목 | 강 수 | 다루는 것 |
|---|---|---|
| ① 원자와 원소 | 4강 | 원자론의 역사, 원자 구조, 주기율표, 동위원소와 방사능 |
| ② 결합과 분자 | 4강 | 이온·공유·금속 결합, 분자의 모양, 분자간 힘, 물의 화학 |
| ③ 반응의 원리 | 4강 | 화학량론, 반응속도, 화학평형, 산염기와 산화환원 |
| ④ 유기화학과 생명의 분자 | 4강 | 탄소의 특권, 작용기, 고분자, 생체분자 |
| ⑤ 물질과 문명 | 4강 | 금속과 재료, 연소와 배터리, 약과 독, 화학산업과 환경 |
