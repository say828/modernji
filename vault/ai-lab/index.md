# AI 커리큘럼 474강

> 중학 수학을 마친 사람이 1강부터 번호 순서대로 따라가면 474강에서 자기가 만든 모델을 최적화하고 운용하고 감사할 수 있게 됩니다.

SCAI LAB의 474강 커리큘럼을 모던지의 문제풀이 방식으로 다시 편찬한 서가입니다. 강의 번호는 과목이 바뀌어도 1번부터 474번까지 끊기지 않고 이어집니다. 지금 몇 강까지 풀었는지만 알면 다음에 무엇을 열지가 정해집니다. 뒤에서 쓰는 도구는 반드시 앞에서 문제로 먼저 끌어내므로, 중간에 다른 책을 찾아볼 필요가 없도록 짰습니다.
